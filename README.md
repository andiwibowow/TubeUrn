# TubeUrn

A simple TubeUrn System for Real time Processing.

TubeUrn is aimed at developers who need a straightforward, dependable solution.

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/TubeUrn.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

TubeUrn is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
